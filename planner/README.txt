==============================================================
  하루 플래너 (Haru Planner) - 설치 및 사용 설명서  v1.0.0
==============================================================

일정 · 할 일 체크리스트 · 목표 · 중요 사항 · 일기를 한곳에서
관리하는 개인용 생활 관리 앱입니다. (PWA, 오프라인 지원)
모든 데이터는 이 기기 안(브라우저 localStorage)에만 저장되고
외부 서버로 전송되지 않습니다.


1. 파일 구성
--------------------------------------------------------------
  index.html              앱 화면
  style.css               디자인 (다크/라이트 모드, 반응형)
  script.js               앱 기능 전체
  manifest.webmanifest    홈 화면 설치용 앱 정보
  service-worker.js       오프라인 실행을 위한 파일 캐싱
  icons/                  앱 아이콘 (192, 512, 마스커블, 애플용, SVG)
  README.txt              이 설명서


2. 실행 방법
--------------------------------------------------------------
[A] PC에서 바로 써 보기 (가장 쉬움)
  - 폴더 안의 index.html 을 더블클릭하면 브라우저에서 열립니다.
  - 모든 기능이 동작하지만, 이 방식에서는 "앱 설치/오프라인 캐시"
    기능은 꺼집니다. (브라우저 보안 규칙상 HTTPS 필요)

[B] PC에서 PWA까지 테스트 (Python 이 설치된 경우)
  - 이 폴더에서 터미널을 열고 다음을 실행:
        python -m http.server 8000
  - 브라우저에서 http://localhost:8000 접속
    (localhost 는 HTTPS 없이도 설치/오프라인 기능이 동작합니다)

[C] 스마트폰에 앱처럼 설치 (HTTPS 무료 호스팅)
  아래 중 하나에 이 폴더의 파일을 그대로 올리면 HTTPS 주소가 생깁니다.
  ※ ZIP 압축을 푼 "파일들"이 사이트의 최상위에 오도록 올리세요.

  - Netlify Drop : https://app.netlify.com/drop
      → 압축 푼 폴더를 브라우저 화면에 끌어다 놓기 → 주소 발급
  - GitHub Pages : 새 저장소에 파일 업로드
      → Settings > Pages > Branch: main 선택 → 주소 발급
  - Cloudflare Pages 등 다른 정적 호스팅도 가능

  ※ 호스팅은 앱 "파일"만 내려받는 용도입니다.
     입력한 데이터는 서버로 가지 않고 각자의 기기에만 저장됩니다.


3. 홈 화면에 설치하기
--------------------------------------------------------------
  안드로이드 (Chrome) : 메뉴(⋮) → "앱 설치" 또는 "홈 화면에 추가"
                        (앱의 설정 화면에 "홈 화면에 앱 설치" 버튼이 뜨기도 함)
  아이폰 (Safari)     : 공유 버튼(□↑) → "홈 화면에 추가"
  PC (Chrome/Edge)    : 주소창 오른쪽의 설치 아이콘 클릭

  설치 후에는 주소창 없는 전체 화면 앱으로 실행되며,
  한 번 열고 나면 인터넷이 없어도 사용할 수 있습니다.


4. 화면 구성과 사용법
--------------------------------------------------------------
  하단 메뉴 : 홈 / 일정 / 할 일 / 목표 / 중요 / 일기
  오른쪽 위 : 🔍 전체 검색 / ☀🌙 테마 전환 / ⚙ 설정·백업
  오른쪽 아래 + 버튼 : 지금 보고 있는 화면의 항목 추가

  ■ 홈 (대시보드)
    - 오늘 날짜/요일, 할 일 완료 수, 오늘 일정 수, 진행·완료 목표 수
    - [바로 찾기] 칸 : 글자를 입력하면 모든 기록을 즉시 검색
    - 중요 사항 바로 보기 버튼, 빠른 추가 버튼(할 일/일정/중요 메모/일기)
    - [오늘의 플랜] : 아침(~11시) → 점심(11~14시) → 오후(14~18시)
                      → 저녁(18시~) 순으로 일정과 할 일을 함께 표시
                      현재 시간대에는 "지금" 표시
    - 진행 중인 목표, 중요 사항 요약, 오늘 기분 + 한 줄 기록

  ■ 할 일 체크리스트
    - 맨 위 입력칸에 쓰고 시간대를 골라 + → 바로 추가
    - 왼쪽 네모를 누르면 V 체크 (다시 누르면 해제)
    - 전체 / 미완료 / 완료 필터, 완료 개수와 달성률 표시
    - 항목을 누르면 수정·삭제, 중요도(높음/보통/낮음) 설정
    - "매일 반복"을 켜면 매일 나타나는 데일리 체크리스트가 됨
      (날짜별로 따로 체크됨. 예: 아침 스트레칭, 영양제)
    - ◀ ▶ 또는 날짜를 눌러 다른 날짜의 할 일 관리

  ■ 일정
    - 제목, 날짜, 시작/종료 시간, 상세 내용, 메모
    - 날짜별 / 다가오는 / 지난 / 완료 탭
    - 시작 시간에 따라 홈 화면의 아침·점심·오후·저녁에 자동 배치

  ■ 목표
    - 단기 / 장기 목표 구분, 상세 설명, 달성 기한(D-day 표시)
    - −10 / +10 버튼 또는 수정 화면의 슬라이더로 진행도 조절
    - 상태 자동 표시 : 시작 전 / 진행 중 / 기한 지남 / 완료
    - V 체크(또는 100% 도달) → "완료한 목표" 탭으로 이동
    - 상단 원 그래프에 전체 목표 달성률 표시

  ■ 중요 사항 보관함
    - 제목, 내용, 중요도, 📌 상단 고정, 검색
    - 고정한 항목은 보관함 맨 위와 홈 화면에 표시

  ■ 일기 · 하루 기록
    - 날짜별 일기 (하루에 한 편), 제목·본문·기분
    - 월별로 자동 정리, 날짜로 찾기, 지난 일기 다시 보기·수정·삭제
    - 홈의 "한 줄 기록"은 오늘 일기에 시간과 함께 자동 추가

  ■ 기타
    - 전체 검색 : 🔍 버튼
    - 완료 항목 모아보기 : 설정 → 모아보기 → 완료 항목
    - 삭제할 때는 항상 확인 창이 뜹니다
    - 꼭 입력해야 하는 칸을 비우면 빨간 안내 문구가 표시됩니다


5. 백업과 복원 (중요!)
--------------------------------------------------------------
  데이터는 이 기기의 브라우저에만 저장됩니다. 다음 경우 사라질 수 있으니
  주기적으로 백업해 두세요.
    - 브라우저의 "인터넷 사용 기록/사이트 데이터 삭제"
    - 앱 삭제, 기기 초기화, 기기 변경

  백업 : 설정 → [백업 파일 저장]
         → haru-planner-backup-날짜.json 파일 다운로드
         → 클라우드 드라이브, 메일 등 안전한 곳에 보관
  복원 : 설정 → [백업에서 복원] → JSON 파일 선택
         → 현재 데이터와 백업 데이터의 개수를 보여 주고
           "덮어쓸지" 한 번 더 확인한 뒤 복원합니다.
  초기화 : 설정 → [모든 데이터 삭제] (확인 후 삭제, 되돌릴 수 없음)

  ※ 같은 주소라도 브라우저가 다르면(예: Chrome ↔ 삼성 인터넷)
     저장 공간이 따로입니다. 기기·브라우저를 옮길 때는 백업/복원을 쓰세요.


6. 앱을 수정했을 때 (개발자용)
--------------------------------------------------------------
  service-worker.js 맨 위의 CACHE_VERSION 값(예: v1 → v2)을 바꿔야
  이미 설치된 기기에서도 새 파일로 갱신됩니다.
  (새 버전은 앱을 한 번 연 뒤 다시 열면 적용됩니다)

  [통과] 목표 진행도 / 상태 표시 / V 완료 → 완료 목록 / 달성률

  [통과] 일기 날짜별 작성 / 중복 날짜 안내 / 날짜순 정리 / 다시 보기
  [통과] 다크 ↔ 라이트 전환 및 재실행 후 유지
  [통과] 새로고침·재실행 후 데이터 유지
  [통과] JSON 백업 / 잘못된 파일 거부 / 덮어쓰기 확인 후 복원
